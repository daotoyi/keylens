# Chrome Web Store 上架草稿

## 基本信息

- 名称：KeyLens — 网页关键信息提取器
- 短名称：KeyLens
- 分类：工作流程与规划
- 语言：简体中文、English
- 版本：1.1.0
- 权限：`activeTab`, `tabs`, `storage`, `scripting`, HTTP/HTTPS 网站访问

## 简短说明

从任意网页提取摘要、联系人、商品和列表数据。空结果不计次，免费版本地可用，Pro 解锁批量与自定义字段。

## 完整说明

KeyLens 把网页里的关键信息整理成可直接使用的结构化结果。

界面支持中文与 English，可跟随浏览器语言或在扩展中即时切换。品牌采用深酒红、绯红与金色视觉体系。

**免费版**

- 一键提取页面标题、摘要和关键点。
- 提取公开显示的邮箱、电话、公司、地址和社交主页。
- 每天 12 次成功提取，CSV 导出。
- 空结果不计次，同一页面重复查看不重复扣次。
- 所有解析在本机完成，不上传页面内容。

**KeyLens Pro**

- 文章结构、商品价格、评分、库存和列表表格。
- 自定义字段，例如“作者, 价格, 公司, 邮箱”。
- 单页最多 300 行。
- 当前窗口最多 8 个标签页批量汇总。
- 选中文本摘要、JSON 和 50 条本地历史。
- 无每日提取次数限制。

**和传统爬虫的区别**

KeyLens 不绕过登录、付费墙、验证码或访问限制。它读取用户当前可正常查看的页面，并先展示提取结果再导出。对复杂动态网站，部分字段可能无法识别；界面会显示空字段与置信度，避免把缺失数据伪装成完整结果。

**隐私**

当前版本没有远程 AI 请求、分析 SDK 或广告追踪。页面文本只在浏览器内处理，设置与用户主动保存的历史保存在 Chrome 本地存储中。

## 商店截图顺序

1. Popup 免费版首页：当前页面 + 免费额度 + 两种可用模式。
2. 页面摘要结果：标题、摘要、关键点、来源与置信度。
3. Pro 列表结果：商品/目录表格和 CSV/JSON。
4. 7 天试用与功能边界：免费版和 Pro 对比。
5. 设置页：本地处理、排除站点和支付入口。
6. 英文界面：页面摘要、English 字段标签与语言切换。

## 权限理由

- `activeTab`：用户点击扩展后读取当前页面。
- `tabs`：显示当前页面标题；Pro 批量处理用户当前已打开的标签页。
- `storage`：保存设置、额度与用户主动保存的历史。
- `scripting`：在扩展更新或安装前已打开的页面中补注入内容脚本。
- `http://*/*`、`https://*/*`：用户需要能够在任意普通网页上手动启动提取。
